# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this extension, please report it **privately** via email:

**roland@tfirst.de**

**Do NOT open a public GitHub issue for security vulnerabilities.**

## What to Include

- Description of the vulnerability
- Steps to reproduce
- Affected versions (if known)
- Potential impact

## Response Time

You can expect an initial response within **7 days**. A fix or mitigation plan will be communicated as soon as possible, typically within 30 days depending on severity.

## Supported Versions

Security fixes are provided for the latest released version. Older versions may receive patches on a case-by-case basis.
