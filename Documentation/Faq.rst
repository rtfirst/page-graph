===
FAQ
===

The widget is empty
===================

Make sure the Dashboard system extension is installed and that your
backend user has permission to view pages. The widget respects TYPO3's
page access permissions.

The graph looks cluttered
=========================

Toggle off "Content Elements" to see only the page tree structure.
Use the search field to find specific pages.

Dark mode is not working
========================

In TYPO3 13+, dark mode is controlled by the ``data-bs-theme``
attribute set via user settings. In TYPO3 12, the widget falls back
to your operating system's color scheme preference.
